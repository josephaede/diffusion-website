Diffusion

Une application macOS personnelle pour publier ses vidéos courtes sur plusieurs réseaux en une fois et suivre leurs statistiques.

Publier partout

Une même vidéo, avec son titre, sa légende, ses hashtags et sa miniature, envoyée sur YouTube, TikTok, Instagram et Facebook.

Programmer

Choix d'une date de publication, avec un calendrier des envois prévus.

Suivre les statistiques

Abonnés, vues, j'aime et commentaires, par réseau et au global, d'après les données fournies par chaque plateforme.

Fonctionnement

Diffusion s'exécute uniquement sur le Mac de son utilisateur. L'application se connecte à chaque réseau avec le système d'autorisation officiel de la plateforme (OAuth), puis communique directement avec ses API officielles :

  • YouTube Data API (Google) ;
  • TikTok Login Kit et Content Posting API ;
  • Graph API de Meta, pour Instagram et les Pages Facebook.

Diffusion n'utilise aucun serveur intermédiaire : les vidéos, les textes et les statistiques passent directement entre le Mac et la plateforme concernée. Le détail figure dans la politique de confidentialité.

Politique de confidentialité

En vigueur le 22 novembre 2026

En bref : Diffusion fonctionne entièrement sur votre Mac. L'application n'a pas de serveur. Elle échange des données uniquement avec les plateformes que vous connectez (Google/YouTube, TikTok, Meta). Elle n'utilise ni publicité, ni outil d'analyse, ni mesure d'audience, et ne vend ni ne partage vos données.

1. Responsable

Diffusion est une application macOS personnelle éditée par Joseph (jojobabyfoot@gmail.com). Dans cette politique, « l'application » désigne Diffusion et « vous » désigne la personne qui l'utilise sur son Mac.

2. Fonctionnement général

Diffusion s'exécute localement sur macOS. Pour se connecter à un réseau, elle ouvre la page d'autorisation officielle de la plateforme dans votre navigateur. La plateforme renvoie ensuite un code d'autorisation à un petit serveur local temporaire, accessible uniquement sur votre Mac à l'adresse http://localhost:8765/callback. Ce serveur se ferme dès que le code est reçu, que la connexion est annulée, ou au bout de 5 minutes.

L'éditeur n'exploite aucun serveur : aucune donnée ne lui est transmise. Toutes les requêtes partent directement de votre Mac vers les API officielles des plateformes.

3. Données traitées

YouTube (Google)

Autorisations demandées : youtube.upload, youtube et youtube.readonly. Elles servent à :

  • envoyer vos vidéos, leur miniature et leurs métadonnées (titre, description, mots-clés, catégorie, confidentialité, date de publication, playlist) ;
  • lire le nom de votre chaîne, le nombre d'abonnés, le nombre total de vues et la liste de vos playlists ;
  • lire vos 25 vidéos les plus récentes : titre, date, miniature, nombre de vues, de j'aime et de commentaires.

TikTok

Autorisations demandées : user.info.basic, user.info.profile, user.info.stats, video.list, video.publish et video.upload. Elles servent à :

  • lire votre nom affiché, votre nom d'utilisateur, votre photo de profil et les compteurs de votre profil (abonnés, abonnements, j'aime, nombre de vidéos) ;
  • lire les options de publication de votre compte (niveaux de confidentialité disponibles, durée maximale) ;
  • envoyer vos vidéos avec leur texte et les options choisies, en publication directe ou vers votre boîte de réception TikTok ;
  • lire vos 20 vidéos les plus récentes : titre, description, date, couverture, lien, vues, j'aime, commentaires et partages.

Instagram et Facebook (Meta)

Autorisations demandées : pages_show_list, pages_read_engagement, business_management, instagram_basic, instagram_content_publish, pages_manage_posts et, facultativement, read_insights et instagram_manage_insights. Elles servent à :

  • lister les Pages Facebook que vous gérez et le compte Instagram professionnel relié à chacune ;
  • connaître les autorisations que vous avez réellement accordées ;
  • publier vos vidéos en Reels sur Instagram et sur la Page Facebook choisie, avec leur texte et leurs options ;
  • lire le nom de la Page, le nom d'utilisateur Instagram et le nombre d'abonnés ;
  • lire vos 25 publications les plus récentes sur chaque réseau : texte, date, lien, miniature, j'aime, commentaires et, si l'autorisation est accordée, vues et partages.

Contenus que vous publiez

Les vidéos, miniatures et textes que vous choisissez sont lus sur votre Mac, puis envoyés uniquement aux plateformes que vous cochez pour la publication.

4. Stockage sur votre Mac

  • Jetons et identifiants : les jetons d'accès et d'actualisation, ainsi que les identifiants des applications développeur que vous saisissez (ID et clés secrètes), sont enregistrés dans le trousseau macOS de votre session. Ils ne sont jamais écrits dans le fichier de données ci-dessous.
  • Données de l'application : réglages, historique des publications, dernières statistiques récupérées, historique quotidien du nombre d'abonnés, brouillon en cours et préférences. Elles sont enregistrées dans le fichier ~/Library/Application Support/Diffusion/donnees.json. Ce fichier n'est pas chiffré par l'application : il est protégé par les permissions de votre session macOS.
  • Les miniatures affichées dans les statistiques sont chargées depuis les serveurs des plateformes au moment de l'affichage.
  • Les notifications (fin d'envoi, erreur) sont des notifications locales de macOS.

5. Partage des données

Vos données ne sont transmises qu'aux plateformes que vous connectez, et uniquement pour les usages décrits ci-dessus. Ces plateformes les traitent selon leurs propres règles de confidentialité : Google, TikTok, Meta.

L'application ne contient aucun outil de publicité, d'analyse, de mesure d'audience ni de rapport d'erreurs envoyé à des tiers. L'éditeur ne vend, ne loue et ne partage aucune donnée.

6. Données des API Google

L'utilisation et le transfert, par Diffusion, d'informations reçues des API Google respectent la Google API Services User Data Policy, y compris ses exigences d'usage limité (« Limited Use »). Ces données servent uniquement aux fonctions décrites dans cette politique. Elles ne sont transférées à personne et ne servent ni à la publicité ni à l'entraînement de modèles d'intelligence artificielle.

7. Conservation et suppression

  • Déconnecter un réseau dans Diffusion (Comptes › Déconnecter) supprime ses jetons du trousseau et les statistiques enregistrées pour ce réseau.
  • L'historique des publications et l'historique des abonnés sont conservés tant que vous ne supprimez pas le fichier donnees.json. Supprimer ce fichier et le dossier ~/Library/Application Support/Diffusion efface toutes les données de l'application.
  • Les identifiants d'application développeur restent dans le trousseau. Vous pouvez les supprimer avec l'app Trousseaux d'accès, en cherchant les éléments du service fr.perso.diffusion.
  • Côté plateformes : la déconnexion dans Diffusion ne révoque pas l'accès auprès de la plateforme. Pour le révoquer :
    • Google : myaccount.google.com/permissions ;
    • Facebook : Paramètres › Intégrations professionnelles ;
    • TikTok : les paramètres de sécurité de l'app, rubrique des applications autorisées.
  • Les vidéos publiées restent sur les plateformes. Vous pouvez les supprimer depuis chaque plateforme.

8. Ce site web

Ce site est hébergé par GitHub Pages. Il n'utilise ni cookies ni scripts de suivi. GitHub peut enregistrer des données techniques de connexion, comme l'adresse IP, selon sa déclaration de confidentialité.

9. Vos droits

Les données de l'application restent sur votre Mac : vous pouvez les consulter, les modifier ou les supprimer directement (voir la section 7). Pour toute question sur cette politique, écrivez à jojobabyfoot@gmail.com.

10. Modifications

Cette politique peut être mise à jour si le fonctionnement de l'application change. La date en haut de la page indique la dernière version.
